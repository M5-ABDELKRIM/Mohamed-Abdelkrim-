## Portfolio Projects

### 1. Hotel Booking Web Application

**Folder:** [hotel-booking-web-app](projects/hotel-booking-web-app)

A full-stack hotel booking system built using Flask and MySQL. The application allows users to create accounts, search hotels, make bookings and manage reservations through a database-driven web interface.

**Technologies:** Python, Flask, MySQL, HTML, CSS, JavaScript

**Key areas demonstrated:**

* Full-stack web development
* Relational database design
* User registration and login
* Booking and reservation logic
* Admin functionality
* Password hashing and secure authentication
* Parameterised SQL queries
* Server-side validation

**Technologies:** Python, Jupyter Notebook, Pandas, data visualisation tools, CSV datasets

**Key areas demonstrated:**

* Security data analysis
* Data cleaning and preprocessing
* Pattern and anomaly detection
* Cybersecurity-focused investigation
* Visualisation of security trends
* Technical reporting and interpretation
